# Changelog

## 0.1.0 — Initial open-source foundation

- Added a framework-neutral guardrail core for context telemetry, deterministic action policy, verification, human checkpoints, and trajectory persistence.
- Added FastAPI proxy, MCP-style stdio, and Python decorator integrations.
- Added stable schema import paths under `honest_agent.schemas.config` and `honest_agent.schemas.trajectory`.
- Added synthetic evaluation harnesses, adversarial regression tests, and GitHub CI.
- Added architecture, operations, integration, development, and product documentation.

This release is intended for local development and controlled pilots. Durable multi-process checkpoint storage, authenticated reviewer operations, provider adapters, and enterprise deployment controls remain future work.
