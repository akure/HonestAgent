## Failures discovered

The first M0 test run found a false positive for the safe `calculate` fixture because unknown actions now require review and the fixture had no explicit safe policy. The same run found that whitespace-only tool names were paused rather than rejected. The first issue was resolved with an explicit pure-calculation rule; the second was resolved by checking `tool_name.strip()` before decision routing.

## Decisions and trade-offs

The unknown-action default remains fail-closed because a safe-looking name cannot prove that an external action is safe. Pure text transformation and calculation are explicit built-in exceptions only for the current synthetic fixtures; customer applications must define their own policy registry as the product matures. Model verifier output remains advisory and cannot authorize irreversible work.
