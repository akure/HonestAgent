## Baseline risk

The provider boundary could parse valid responses and reject malformed ones, but it did not expose typed transport faults, define retry limits, compare independent providers, propagate cancellation explicitly, or record latency and outcome metrics.

## Implementation

1. Added typed `ProviderTimeout`, `ProviderUnavailable`, `ProviderContractError`, and `ProviderDisagreement` failures.
2. Mapped HTTP timeout, transport, status, and JSON contract failures in the OpenAI-compatible adapter.
3. Added bounded retries for transient failures only.
4. Preserved `asyncio.CancelledError` propagation with no retry or swallowing.
5. Added optional secondary-provider comparison with fail-closed disagreement handling.
6. Added payload-free latency and outcome metrics with p50/p95 snapshot support.
7. Added deterministic offline fault-matrix tests using `httpx.MockTransport` and provider doubles.
