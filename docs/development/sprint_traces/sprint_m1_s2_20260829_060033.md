## Failures discovered

No failing regression was found after the M1 implementation. The new restart test proved the important boundary: a fresh `HonestGuard` instance can resolve a pending trajectory created by an earlier instance.

## Decisions and trade-offs

The first implementation uses atomic JSON replacement because it adds restart safety without introducing a database dependency into the reproducible prototype. The storage interface is intentionally replaceable. Multi-worker safety, retention, expiry, and append-only event semantics are not claimed by the file implementation and remain explicit next tasks.
