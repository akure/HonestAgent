## Failures discovered

The first M2 run issued a handoff for rejected blank-tool decisions because the branch used “not paused” rather than “proceed.” The test caught the unsafe contract error; issuance is now explicitly limited to `PROCEED`.

## Decisions and trade-offs

HMAC signing keeps the prototype dependency-free and makes payload mutation detectable. The default secret is development-only. A production implementation must inject a secret from a secret manager and validate the handoff in the executor or upstream gateway, not only in the application process.
