## Baseline risk

RAG systems introduce untrusted documents, cross-tenant retrieval risk, stale citations, sensitive-data egress, and prompt injection. CX0 had evidence metadata, but no retrieval boundary combined these controls or separated content from authorization.

## Implementation

1. Added `RetrievalChunk` as an in-memory content plus `EvidenceEnvelope` pair.
2. Added `RAGEvidenceBoundary` with tenant and source allowlists.
3. Enforced egress class and freshness checks.
4. Required trusted evidence for high-impact workflows.
5. Added deterministic prompt-injection signal patterns that pause rather than authorize.
6. Added high-impact citation coverage checks.
7. Added authorization separation so retrieved content cannot bear authority unless explicitly trusted and attributable.
