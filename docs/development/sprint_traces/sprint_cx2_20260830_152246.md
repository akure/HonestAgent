## Baseline risk

The legacy handoff protected a single request and trajectory but did not represent the full authority context of a complex workflow. A replayed or altered handoff could otherwise be confused with a current step, tenant, evidence snapshot, or destination.

## Implementation

1. Added versioned `ExecutionHandoffV2` claims.
2. Used deterministic `ToolIntent.canonical_hash()` as the signed semantic identity.
3. Added current/previous-secret validation compatibility through the existing signer rotation slots.
4. Added expiry bounded by both signer TTL and workflow deadline.
5. Added `CallableExecutor.execute_v2()` for pre-invocation enforcement in supported integrations.
6. Preserved legacy v1 behavior only as an explicit compatibility path.
