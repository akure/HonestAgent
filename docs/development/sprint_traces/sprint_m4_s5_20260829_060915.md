## Failures discovered

The initial test expected arbitrary input fields, including a secret-like field, to appear in the report. This was rejected as an unsafe export contract. The report now uses a fixed output schema and omits unrecognized fields.

## Decisions and trade-offs

The report is intentionally generated from raw evaluation artifacts rather than a dashboard. This keeps the MVP auditable and reproducible while postponing UI investment until customers demonstrate repeated usage and a stable event model.
