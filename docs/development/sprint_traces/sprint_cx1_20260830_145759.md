## Baseline risk

CX0 made workflow identity and budget intent explicit, but no durable manager consumed those budgets. A resumed worker could reset counters, concurrent workers could race past limits, and cancelled or expired work could continue to reserve capacity.

## Implementation

1. Added `DurableWorkflowStore` using SQLite WAL and transactional context records.
2. Added atomic `reserve()` with typed `BudgetExceeded` results.
3. Added cancellation state and `WorkflowCancelled` fail-closed outcome.
4. Added deadline checks and wall-clock budget fields.
5. Added durable restart, concurrent cap, cancellation, expiry, and no-mutation-on-failure tests.
