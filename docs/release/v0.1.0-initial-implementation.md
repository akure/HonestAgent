## Included scope

This baseline includes the generic fail-closed safety kernel, signed tenant-scoped domain policy-pack foundation, six synthetic domain-pack examples, framework-shaped adapters for LangChain, LangGraph, CrewAI, AutoGen/AG2, and LlamaIndex, and the associated local regression and assurance suites. It also includes the workflow/RAG enhancement plan and the mature Git workflow.

## Validation expectations

The baseline is created from a clean `main` commit after the repository’s existing test and documentation checks. Future release records must replace this statement with exact command output and immutable artifact references for the release commit.

The repository’s current local evidence includes the full regression suite, domain-pack JSON validation, five offline adapter demos, Python compilation, `git diff --check`, and a dependency audit reporting no known vulnerabilities at the time it was run. SBOM evidence is deployment/build dependent and must be regenerated for each release environment.

## Known limitations

This tag does not represent regulatory certification, customer validation, production authorization, or a guarantee of safe autonomous execution. The framework does not yet provide the complete durable workflow context, first-class RAG evidence envelope, workflow-level budgets, delegated capability attenuation, production framework-version compatibility, distributed exactly-once semantics, or deployment-specific monitoring, identity, egress, audit, recovery, and kill-switch evidence described in the workflow/RAG enhancement plan.

All domain packs and framework examples are opt-in, synthetic, credential-free, and side-effect-free. Production deployments require an accountable owner, commercial licensing compliance, pinned dependencies, target-environment validation, human approval for consequential actions, and a separate release decision.

## Rollback

Rollback is performed by deploying a previously tested immutable tag or disabling an opt-in pack/example. The tag must not be rewritten or deleted to conceal a defect. Security fixes require a new patch release and regression evidence.
